# ENS160 气体传感器

I2C 数字气体传感器，检测 VOCs 和 CO2 当量。

## 硬件

- I2C 地址: 0x52（MISO/ADDR 低电平）或 0x53（高电平）
- 挂载于 I2C1，引脚重映射至 GPIO 17 (SDA) / GPIO 18 (SCL)
- 速率 100kHz

## 数据流

```
┌─────────────┐   I2C write 0x10=0x02    ┌──────────────┐
│   ESP32-S3  │ ─────────────────────────→│   ENS160     │  设为标准模式
│   (Master)  │                            │   (Slave)    │
│             │   I2C read  0x20          │              │
│             │ ←─────────────────────────│              │  DEVICE_STATUS
│             │                            │              │  bit1=NEWDAT
│             │   I2C read  0x21/22/24    │              │
│             │ ←─────────────────────────│              │  AQI/TVOC/eCO2
└─────────────┘                            └──────────────┘
```

1. 初始化时设 OPMODE (0x10) = 0x02（标准气体传感模式）
2. 轮询 DEVICE_STATUS (0x20) bit1 等待新数据
3. 依次读取 AQI (0x21)、TVOC (0x22)、eCO2 (0x24)、T (0x30)、RH (0x32)
4. 每次读取 0x20-0x37 范围寄存器时，硬件自动更新 DATA_MISR 校验值

## 日志字段

```
I (10322) ens160: AQI:1(优) TVOC:7 ppb eCO2:400 ppm T:25.0°C RH:50.0% [正常]
```

| 字段 | 寄存器 | 格式 | 说明 |
|------|--------|------|------|
| AQI | 0x21[2:0] | 1-5 | 空气质量指数（UBA 标准），1=优 2=良 3=中等 4=差 5=劣 |
| TVOC | 0x22:0x23 | uint16 LE，单位 ppb | 总挥发性有机物浓度 |
| eCO2 | 0x24:0x25 | uint16 LE，单位 ppm | 基于 VOCs+H2 计算的等效 CO2 浓度 |
| T | 0x30:0x31 | uint16 LE，K×64→°C | 计算中使用的温度（默认 25°C，可写入 TEMP_IN 补偿） |
| RH | 0x32:0x33 | uint16 LE，%×512→% | 计算中使用的相对湿度（默认 50%，可写入 RH_IN 补偿） |
| [状态] | 0x20[3:2] | — | 输出有效性：正常=0 / 预热=1 / 启动=2 / 无效=3 |
