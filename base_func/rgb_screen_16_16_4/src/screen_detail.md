屏幕规格：64列 × 16行，由 4 块 16×16 的 WS2812 点阵屏横向拼接而成。
坐标定义：(x, y)，x=0~63（左→右），y=0~15（上→下）。
像素总数：1024 个，WS2812 地址范围 0~1023。

块划分：
- 第1块：x=0~15，地址偏移 0
- 第2块：x=16~31，地址偏移 256
- 第3块：x=32~47，地址偏移 512
- 第4块：x=48~63，地址偏移 768

单块内部分布（16×16）：
- 按列扫描，蛇形（zig-zag）
- 列号 col_in_block = x % 16（0~15）
- 偶数列（col_in_block 为 0,2,4...14）：从上到下 y=0→15，地址递增
- 奇数列（col_in_block 为 1,3,5...15）：从下到上 y=15→0，地址递增
- 每列占 16 个连续地址

地址计算逻辑：
1. 块号 = x // 16
2. 块内列 = x % 16
3. 块内地址：
   - 偶数列：col_in_block × 16 + y
   - 奇数列：col_in_block × 16 + (15 − y)
4. 最终地址 = 块号 × 256 + 块内地址
